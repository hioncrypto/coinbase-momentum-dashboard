TradingView + Kalshi TARGET on Android

Auto horizontal line for Kalshi’s 15-minute Target Price on a BTCUSD TradingView chart.

The TradingView Play Store app cannot run this. Use the TradingView website in Firefox.

  1. Install Firefox on Android
  2. Install the Tampermonkey add-on in Firefox
  3. Install the userscript kalshi-tv-target.user.js from this project
  4. In Firefox open tradingview.com → BTCUSD chart
  5. TARGET line updates automatically each 15m Kalshi window

Prefer a dedicated phone chart (not TradingView’s UI)? Open the Kalshi BTC Target PWA
