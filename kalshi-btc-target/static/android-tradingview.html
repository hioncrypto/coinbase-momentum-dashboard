Android only

No computer. Auto Kalshi 15m TARGET line on TradingView in Firefox.

Use Firefox + TradingView website — not the TradingView app.

  1. Install Firefox
    Google Play · Firefox
  2. Install Tampermonkey inside Firefox
    Add Tampermonkey
  3. In Tampermonkey: Dashboard → + → delete template → paste kalshi-tv-target.user.js → save → Enabled
    Open userscript file
  4. Open BTCUSD on TradingView in Firefox
    Open TradingView BTCUSD
  5. Confirm dashed green TARGET line — it auto-updates every 15 minutes
