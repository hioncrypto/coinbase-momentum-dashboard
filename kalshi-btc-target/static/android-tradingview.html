TradingView + Kalshi TARGET on Android

Auto horizontal line for Kalshi’s 15-minute Target Price on a BTCUSD TradingView chart. No GitHub required once this page is open.

Use the TradingView website in Firefox — not the Play Store TradingView app.

  1. Install Firefox for Android
    Open Firefox on Google Play
  2. In Firefox, install Tampermonkey
    Open Tampermonkey add-on
  3. Install the Kalshi TARGET userscript
    Install userscript
  4. Open TradingView in Firefox and load a BTCUSD chart
    Open TradingView BTCUSD
  5. TARGET line updates automatically each Kalshi 15m window

Prefer a dedicated phone chart (not TradingView’s UI)? Open the Kalshi BTC Target chart
